# Data Cleaning & Reporting Automation

## Project Overview
This project automates data cleaning, preprocessing, and sales reporting using Python.

## Objectives
- Handle missing values.
- Identify and remove duplicate records.
- Standardize inconsistent data.
- Calculate total sales and revenue.
- Generate automated reports and visual summaries.

## Technologies Used
- Python
- Pandas
- Matplotlib
- OpenPyXL
- Jupyter Notebook

## Key Features
- Automated missing-value handling
- Duplicate removal
- Data standardization
- Sales calculations
- Category-wise and city-wise analysis
- Automated Excel and CSV reports
- Visual sales charts

## How to Run
1. Install the required packages:
   `pip install pandas matplotlib openpyxl jupyter`
2. Open the notebook in Jupyter.
3. Run the notebook cells in order.

## Outcome
A reusable Python workflow for cleaning sales data and generating reports automatically.
